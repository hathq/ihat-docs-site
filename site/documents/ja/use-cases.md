## 役割を定義する

HATは目的、操作、必要な権限を記述する単位です。利用する前に、その役割と境界を確かめます。

::document-link{title="機能を見る" href="/hat/specification" icon="/brand/icons/layers.svg"}
::

## 公開されたものを探す

指定されたリポジトリのリリースをRegistryで探す構成です。ソースの公開と配布版は区別します。

::document-link{title="機能を見る" href="/hat/registry" icon="/brand/icons/search.svg"}
::

## 手元で組み合わせる

Hatterをローカルに置き、必要なHATを取得・検証する設計です。インストールと実行の許可を分けます。

::document-link{title="機能を見る" href="/hat/local-first" icon="/brand/icons/device.svg"}
::
