## 1. 環境を確認する

LinuxまたはWSLのx86\_64環境と、信頼できるNode 22.23.4以降または24.22.1以降が必要です。Ubuntu 24.04で検証しています。Nodeの自動インストールやWindowsネイティブへの導入は行いません。

## 2. コマンドを実行する

インストールページでコマンドをコピーし、端末に貼り付けて実行します。表示されたバージョンと配置先を確認して「install」と入力してください。取得したインストーラーと製品アーカイブは実行・展開前に検証します。

::document-link{title="インストールコマンドへ" href="/download"}
::

## 3. Hatterを起動する

インストール完了後、端末で \~/.local/bin/hatter を実行し、表示されるローカルURLをブラウザで開きます。既存のPATHに \~/.local/bin があれば hatter でも起動できます。シェル設定の自動変更や常駐サービスの登録は行いません。

## 4. 作業対象と権限を選ぶ

インストールだけではデータストア、保存キー、役割、実行権限は初期化されません。必要な準備を個別に確認し、HATの取得と実行の許可を分けて進めます。Registryとの実同期は準備中です。
